# 地形面片标注工具（surface_studio）

代码：`src/nav_terrain/scripts/`，测试：`src/nav_terrain/test/test_surface_seg.py`。

软件打开场地模型或先验点云后，自动把地面分割成**平面 / 斜面面片**，只给出几何信息（坡度、朝向、面积、高度等），
**不猜测地形类型**。类型、可通过性、方向和面片大小全部由人工标注 / 修正，最后导出 Nav2 地形包。

## 1. 启动

```bash
~/.venvs/terrain/bin/python src/nav_terrain/scripts/surface_studio.py [文件]
```

`[文件]` 可省略，也可以是模型、点云 / 建图目录或 `.surf.npz` 工程。依赖：numpy、scipy、PyQt5、opencv、pyyaml；
STEP 需要 `cadquery-ocp`，三维预览需要 `open3d`（虚拟环境 `~/.venvs/terrain` 已装好）。

## 2. 输入

| 输入 | 格式 | 坐标系 | 说明 |
|---|---|---|---|
| 官方场地模型 | `.stl`（二进制 / ASCII）、`.step` / `.stp`、`.npz`（V, F） | 场地（field） | 精度最高。STEP 单位 mm，按“STEP 原点偏移”（默认 `0, 1624.3, -1941` mm，RMUC2027）换算到米；首次镶嵌结果缓存在 `~/.cache/nav_terrain` |
| 先验点云 | 建图目录（`keyframes.txt` + `clouds/*.pcd`，推荐）或单个 `.pcd` | 地图（map） | 先生成高程图再分割，精度低于模型。降采样后的 `map.pcd` 点太少，请选建图目录 |
| 标注工程 | `.surf.npz` | 与来源一致 | 本工具保存的工程，继续编辑 |
| 配准初值（可选） | `terrain.json` 中的 `registration` | map → field | 点云配准到模型时作为 ICP 初值 |

## 3. 处理流程

1. **高程栅格**
   - 模型：每格一条竖直射线，地面 = 头顶净空 ≥ `min_clear` 的最低朝上表面（隧道里取地板而不是顶棚），记录净空；
     坡度直接取俯视看到的三角面法向（精确，不平滑）。
   - 点云：栅格 `max(resolution, cloud_res)`（默认 5 cm）；每格取上方空出 ≥ `min_clear` 的最低点簇为地面（同样能识别隧道地板和净空），
     补小于 0.5 m² 的空洞，保边滤波；坡度由高差在 `cloud_smooth` 半径内平滑求得。
2. **分割**：相邻格高差 > `jump` 或一侧有顶棚一侧没有时断开；坡度 < `flat_deg` 为平面；相邻斜面法向差 < `normal_deg` 合并；
   小于 `min_area` 的碎块并入相邻面片，仍然过小的碎块并入高差 ≤ `clutter_dz` 的大块，否则相连碎块合成一个“杂物”面片。
3. **面片几何**：每块最小二乘平面，得到坡度、上坡方位、拟合残差；多向坡（如堡垒六边形坡、山脊）按俯视方向分组，每个坡面单独给方向。
4. **人工标注与修正**（见第 5 节）。
5. **导出**（见第 4 节）。

## 4. 输出

### 4.1 标注工程 `*.surf.npz`（保存工程 Ctrl+S）

| 字段 | 内容 |
|---|---|
| `z` | float32 [H, W] 地面高程，NaN = 无数据 |
| `clearance` | float32 [H, W] 头顶净空，inf = 露天 |
| `gx`, `gy` | 仅模型：每格精确坡度 dz/dx、dz/dy |
| `seg` | int32 [H, W] 自动分割结果 |
| `owner` | int32 [H, W] 当前面片编号（含人工大小修正） |
| `meta` | JSON：`format`、`frame`（field / map）、`source`、分割参数、`resolution`、`origin`、`reg`（配准）、`ann`（标注） |

`ann` 每个面片：`type`（标签编号，-1 = 未标注）、`passable`、`dir`（手动方向，度；null = 几何方向）、`rev`（几何方向反向）。
栅格约定同 `terrain_map`：行 = y（第 0 行最小 y），`origin` 为格 (0, 0) 左下角坐标。

### 4.2 Nav2 地形包（导出 Nav2 Ctrl+E，选择 terrain_dir）

| 文件 | 内容 |
|---|---|
| `terrain.msgpack` | 合成后的标注地图（terrain / direction / elevation），可用 `terrain_export.py` 换参数重新导出 |
| `nav_map.pgm` / `.yaml` | Nav2 静态地图（scale 模式）。障碍致命；障碍旁膨胀带上限 `max_band_cost`；方向地形本体代价 `terrain_cost` |
| `speed_mask.pgm` / `.yaml` | 限速百分比（raw 模式）：隧道 35、坡道 60、起伏路段 50，其余 0 = 不限速 |
| `direction_map.png` | 三通道：方向角编码 / 强度 / 标签（HWSentryNav26 格式） |
| `terrain.png` | 标签颜色预览 |
| `zones.yaml` | 每个连通方向区域：类型、中心、轴线、尺寸、入口 / 出口、高度范围，以及通行方向、是否可反向、是否贴合中轴等策略。同一标签的连通域还会在**方向突变 > `--direction-split-deg`（默认 20°）**处断开，所以多向坡（堡垒六边形坡、山脊）每个坡面各出一条记录，而不是一个盖住整个环的框 |
| `terrain.json` | 栅格元数据、各标签格数、膨胀参数、限速、`frame`、`registration`，以及 `unannotated_cells`、`blocked_cells`、`no_data_cells` |

**导出规则**：标注类型照写；**禁止通过、无数据、未标注的格子一律为障碍**（默认不可通行，只需标出能走的地方）。
方向：坡道 = 上坡方向，台阶 = 由低到高，隧道 / 起伏 = 通行方向（长轴）；多向坡按各坡面分别写入（方向栅格与 `zones.yaml` 都是每个坡面独立一条）。
Nav2 将这些方向区域统一作为有方向约束的通行区处理。当前默认策略为：隧道和起伏双向沿轴通过；坡面和台阶沿标注的正方向通行并朝向该方向；隧道贴中轴，开放地形保留规划器选定的横向位置。导出到 `zones.yaml` 的策略字段可供 Nav2 直接读取。

## 5. 功能与操作

### 查看与选择
- 左键选中，Ctrl+左键加选 / 取消，Shift+拖动框选；中键或右键拖动平移，滚轮缩放，F 适应窗口。
- “几何信息”显示：平面 / 斜面 / 多向斜面、坡度、上坡朝向、面积、尺寸、长轴、高度范围、平整度、头顶净空、边缘高差方向、相邻面片高差。
- “面片列表”页可按面积筛选、只看未标注、排序，双击定位；底部显示标注进度。
- G：选同高相连平面——从选中面片扩展到所有未被台阶隔开、未标注或同类型的平面。

### 标注
- 1–8 设类型，0 清除；X 切换允许 / 禁止通过；R 方向反向；输入角度 = 手动方向；“用几何方向”恢复自动方向。

### 大小修正
| 工具 | 键 | 作用 |
|---|---|---|
| 选择 | V | 默认工具 |
| 画笔 | B | 拖动涂抹区域（半径可调） |
| 矩形 | U | 拖出矩形区域 |
| 套索 | L | 画任意多边形区域 |
| 切割线 | K | 一条线完整穿过面片，切成多块（各块继承标注） |

画笔 / 矩形 / 套索的区域按“画出的区域”处理：新建面片（继承原标注）/ 并入选中面片 / 恢复自动分割；
“只改选中面片里的格子”默认开启。另有：M 合并选中，+ / - 扩大 / 缩小一圈，“恢复自动分割范围”。

例：一块平地里只有一部分不能通过 → 选中平地 → U 框出那部分（成为新面片）→ X 禁止通过。

所有编辑可 Ctrl+Z 撤销、Ctrl+Y 重做。修改分割参数后“重新分割”，已有标注转到重叠超过一半的新面片上（人工大小修正会被新分割替换）。

### 点云配准到模型
1. 先打开模型并标注（或在“点云配准”页载入参考场地 / 工程）。
2. 打开点云，填写初值或从 `terrain.json` 读取，运行 ICP（显示残差 p50 / p90 和内点率，p50 < 6 cm 且内点 > 60 % 视为成功）。
3. “采用模型面片和标注”：点云稀疏，自己的分割会把同一块地形切成很多碎片，所以每个点云格子改用其中心下方的模型面片（编号同模型），并复制模型标注，方向按配准旋转。高程仍用点云自己的；点云没有数据的格子（隧道顶棚下、未扫到的区域）用模型高程补齐，同样归入模型面片；只有模型范围外的格子没有面片（导出为障碍）。点云原有的面片和标注被替换，撤销历史清空；之后可用画笔等工具按点云实际情况修正，“恢复自动”恢复到模型面片。注意“重新分割”会重新用点云自己的分割。

### 其他
- 三维预览：open3d 新窗口显示当前着色的高程点。
- 分割参数页可调所有参数（第 3 节），分辨率和点云高度范围需重新打开文件生效。
- 重新导出（`terrain_export.py` 或 Ctrl+E）可选 `--direction-split-deg`：默认 20°，用于把多向坡按坡面拆成多个 zone；设 180 关闭拆分（旧行为，一个框盖住整个环并带 `direction varies` 警告）。拆分只作用于 zone 划分，`terrain.msgpack` 的标签 / 方向栅格不变。

## 6. 已知局限
- 点云只能看到扫描到的区域；墙脚和杂物周围会有杂物面片，需要人工归类（未标注即障碍）。
- 一级 / 二级 / 高台阶的区别目前只在标签上，导出代价相同。
