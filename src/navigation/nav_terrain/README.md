# nav_terrain

Python 模块安装到 ROS 工作区环境。`terrain_map.TerrainMap` 读写地形栅格，`point_cloud` 和 `mesh_io` 读取输入，`surface_seg` 分割面片，`surface_project.Project` 管理标注。`terrain_export.export` 接受 `ExportConfig`、输出目录和来源标识，导出导航地形包。运行时由 `terrain_obstacles.py` 读取该包并过滤实时观测。[源码](nav_terrain)、[测试](test)

软件打开场地模型或先验点云后，自动把地面分割成**平面 / 斜面面片**，只给出几何信息（坡度、朝向、面积、高度等），
**不猜测地形类型**。类型、可通过性、方向和面片大小全部由人工标注 / 修正，最后导出 Nav2 地形包。

## 1. 启动

从仓库根目录运行 `bash tools/start_web_ui.sh`，在浏览器打开「地形标注」。可输入工作区内的模型、点云、建图目录或 `.surf.npz` 工程路径。地形功能使用 numpy、scipy、opencv 和 pyyaml。读取 STEP 需要在 WebUI 的 Python 环境安装 `cadquery-ocp`。[工作台操作与 STEP 环境配置](../../../docs/web-ui.md)

## 2. 输入

| 输入 | 格式 | 坐标系 | 说明 |
|---|---|---|---|
| 官方场地模型 | `.stl`（二进制 / ASCII）、`.step` / `.stp`、`.npz`（V, F） | 场地（field） | 精度最高。STEP 单位 mm，按“STEP 原点偏移”（默认 `0, 1624.3, -1941` mm，RMUC2027）换算到米；首次镶嵌结果缓存在 `~/.cache/nav_terrain` |
| 先验点云 | 建图目录（`keyframes.txt` + `clouds/*.pcd`，推荐）或单个 `.pcd` | 地图（map） | 先生成高程图再分割，精度低于模型。降采样后的 `map.pcd` 点太少，请选建图目录 |
| 标注工程 | `.surf.npz` | 与来源一致 | 本工具保存的工程，继续编辑 |
| 配准初值（可选） | `terrain.json` 中的 `registration` | map → field | 点云配准到模型时作为 ICP 初值 |

## 3. 处理流程

编辑器和脚本通过 [`surface_seg`](nav_terrain/surface_seg/__init__.py) 调用分割。包内 `_height` 把三角网格或点云转换为高程与净空栅格，`_grid` 定义坐标、参数和梯度，`_regions` 生成面片编号，`_geometry` 计算面片属性。`Project.segment()` 直接复用分割时的梯度，重分割后仅当旧面片覆盖新面片超过一半时才继承标注。

[`Project`](nav_terrain/surface_project.py) 管理编辑状态，委托 `project_history` 保存撤销记录、`project_archive` 读写 `.surf.npz`，通过 `registration.FieldProjection` 将模型面片和高程投影到点云栅格。界面的面片详情和列表在 `studio_inspector`，二维着色在 `studio_render`。导出和离线编辑均可直接调用 `Project`。

1. **高程栅格**
   - 模型：每格一条竖直射线，地面 = 头顶净空 ≥ `min_clear` 的最低朝上表面（隧道里取地板而不是顶棚），记录净空；
     坡度直接取俯视看到的三角面法向（精确，不平滑）。
   - 点云：栅格 `max(resolution, cloud_res)`（默认 5 cm）；每格取上方空出 ≥ `min_clear` 的最低点簇为地面（同样能识别隧道地板和净空），
     补小于 0.5 m² 的空洞，保边滤波；坡度由高差在 `cloud_smooth` 半径内平滑求得。
2. **分割**：相邻格高差 > `jump` 或一侧有顶棚一侧没有时断开；坡度 < `flat_deg` 为平面；相邻斜面法向差 < `normal_deg` 合并；
   小于 `min_area` 的碎块并入相邻面片，仍然过小的碎块并入高差 ≤ `clutter_dz` 的大块，否则相连碎块合成一个“杂物”面片。
3. **面片几何**：每块最小二乘平面，得到坡度、上坡方位、拟合残差；多向坡（如堡垒六边形坡、山脊）按俯视方向分组，每个坡面单独给方向。
4. **人工标注与修正**（见第 5 节）。
5. **导出**（见第 4 节）。

## 4. 输出

### 4.1 标注工程 `*.surf.npz`

| 字段 | 内容 |
|---|---|
| `z` | float32 [H, W] 地面高程，NaN = 无数据 |
| `clearance` | float32 [H, W] 头顶净空，inf = 露天 |
| `gx`, `gy` | 仅模型：每格精确坡度 dz/dx、dz/dy |
| `seg` | int32 [H, W] 自动分割结果 |
| `owner` | int32 [H, W] 当前面片编号（含人工大小修正） |
| `meta` | JSON：`format`、`frame`（field / map）、`source`、分割参数、`resolution`、`origin`、`reg`（配准）、`ann`（标注） |

`ann` 每个面片：`type`（标签编号，-1 = 未标注）、`passable`、`dir`（手动方向，度；null = 几何方向）、`rev`（几何方向反向）。
栅格约定同 `terrain_map`：行 = y（第 0 行最小 y），`origin` 为格 (0, 0) 左下角坐标。

### 4.2 Nav2 地形包

| 文件 | 内容 |
|---|---|
| `terrain.msgpack` | 合成后的标注地图（terrain / direction / elevation / clearance），可用 `terrain_export.py` 换参数重新导出 |
| `nav_map.pgm` / `.yaml` | Nav2 静态地图（raw 模式）：像素 0 = 空闲，1–99 = 代价，100 = 障碍，255 = 未知（ROS 占用值 -1）。障碍旁膨胀带上限 `max_band_cost`；方向地形本体代价 `terrain_cost` |
| `speed_mask.pgm` / `.yaml` | 限速百分比（raw 模式）：隧道 35、坡道 60、起伏路段 50，其余 0 = 不限速 |
| `direction_map.png` | 三通道：方向角编码 / 强度 / 标签（HWSentryNav26 格式） |
| `terrain.png` | 标签颜色预览 |
| `zones.yaml` | 每个连通方向区域：类型、中心、轴线、尺寸、入口 / 出口、高度范围，以及通行方向、是否可反向、是否贴合中轴等策略。同一标签的连通域还会在**方向突变 > `--direction-split-deg`（默认 20°）**处断开，所以多向坡（堡垒六边形坡、山脊）每个坡面各出一条记录，而不是一个盖住整个环的框 |
| `terrain.json` | 栅格元数据、各标签格数、膨胀参数、限速、`frame`、`registration`，以及 `unannotated_cells`、`blocked_cells`、`no_data_cells` |

**导出规则**：有观测的格子按标注类型写入；有观测但禁止通过或未标注的格子为障碍。**无高程观测的格子为 UNKNOWN（terrain 标签 255）**，导出后 `/nav_map` 中为 -1，不作为静态障碍膨胀源。未知区域的方向强度为 0，地面高度为 NaN。
全局和局部代价地图均启用 `track_unknown_space`，保留未知区域；实时点云清除射线可将实际观测到的空闲区域更新为空闲。规划器默认 `allow_unknown: false`，只通过已知可通行区域。旧地形包可以从 `.surf.npz` 工程重新导出；直接重新导出带高程的旧 `terrain.msgpack` 时，高程为 NaN 的格子也会转换为 UNKNOWN。
方向：坡道 = 上坡方向，台阶 = 由低到高，隧道 / 起伏 = 通行方向（长轴）；多向坡按各坡面分别写入（方向栅格与 `zones.yaml` 都是每个坡面独立一条）。
Nav2 将这些方向区域统一作为有方向约束的通行区处理。当前默认策略为：隧道和起伏双向沿轴通过；坡面和台阶沿标注的正方向通行并朝向该方向；隧道贴中轴，开放地形保留规划器选定的横向位置。导出到 `zones.yaml` 的策略字段可供 Nav2 直接读取。

## 5. 功能与操作

### 查看与选择
- 左键选中，Ctrl 或 ⌘ 加选，Shift+拖动框选。选择平移工具或用中键、右键拖动，滚轮或按钮缩放。
- 选中单个面片后查看坡度、通行方向、面积、尺寸、高程范围和净空。列表支持筛选未标注面片。
- 「选同高平面」从选中面片扩展到未被台阶隔开、未标注或同类型的相邻平面。

### 标注
- 在右侧设置类型和通行性。输入角度应用手动方向，点击「反向」旋转 180°，用「几何方向」恢复自动方向。

### 大小修正
| 工具 | 作用 |
|---|---|
| 选择 | 默认工具 |
| 画笔 | 拖动涂抹区域，半径可调 |
| 矩形 | 拖出矩形区域 |
| 套索 | 画任意多边形区域 |
| 切割线 | 一条线完整穿过面片，切成多块并继承标注 |

画笔 / 矩形 / 套索的区域按“画出的区域”处理：新建面片（继承原标注）/ 并入选中面片 / 恢复自动分割；
「限于选中范围」默认开启。可合并选中面片、扩大或缩小一圈，或用「恢复范围」还原分割边界。

一块平地只有一部分可通行时，可选择平地，使用矩形工具框出禁行部分并新建面片，再将新面片设为禁止通行。

用按钮撤销或重做面片编辑。重新分割会把已有标注转到重叠超过一半的新面片上，并将人工修正的边界换成分割结果。

### 点云配准到模型
1. 在「场地模型」打开 STEP 等场地模型并标注，或打开已有的场地标注工程。
2. 切换到「建图点云」打开点云。使用工程初值、从 `terrain.json` 读取初值，或手动填写地图到场地的平移和航向。运行 ICP 后检查叠加的青色边界、残差 p50 / p90 和内点率，可参考 p50 < 6 cm 且内点 > 60% 的指标。
3. “采用模型面片和标注”：点云稀疏，自己的分割会把同一块地形切成很多碎片，所以每个点云格子改用其中心下方的模型面片（编号同模型），并复制模型标注，方向按配准旋转。高程仍用点云自己的；点云没有数据的格子（隧道顶棚下、未扫到的区域）用模型高程补齐，同样归入模型面片；只有模型范围外的格子没有面片（导出为障碍）。点云原有的面片和标注被替换，撤销历史清空；之后可用画笔等工具按点云实际情况修正，“恢复自动”恢复到模型面片。注意“重新分割”会重新用点云自己的分割。

### 其他
- 可在打开源文件前设置分辨率和点云高度范围。工程打开后，可在「重新分割」调整高差和坡度分界等参数。
- 导出参数中的方向拆分角默认为 20°，用于把多向坡按坡面拆成多个 zone。设为 180° 可关闭拆分。也可通过 `terrain_export.py --direction-split-deg` 重新导出。

## 6. 已知局限
- 点云只能看到扫描到的区域；墙脚和杂物周围会有杂物面片，需要人工归类（未标注即障碍）。
- 一级 / 二级 / 高台阶的区别目前只在标签上，导出代价相同。
