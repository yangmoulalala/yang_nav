z-localization 程序流程

前端 ZLIO 输出局部、连续、会慢慢漂移的里程计；后端把它放进全局地图坐标系，只发布 map → lio_odom 这一个修正量。五张图从整体讲到状态机和重置。数值取自 bringup/config/sim/*.yaml，坐标系名是 bringup 的配置值。各步骤的函数级细节见细节版。

/frontend/sessiontransient local；启动、重置、reset_required、failed 时发布。

建议的读代码顺序

  1. frontend/apps/node.cpp：onImu → work → collect，看懂线程和发布。
  2. frontend/src/odometry.cpp：process()，LIO 一次观测做了什么。
  3. backend/apps/node.cpp、node_input.cpp：后端怎么被驱动。
  4. backend/src/localization.cpp：ingestFrame、runMaintenanceCycle、execute。
  5. backend/src/localization_state.cpp：状态转移。
  6. 细节：observation.cpp（跟踪判定）、localization_recovery.cpp 与 relocalization*.cpp（重定位）、reset_coordinator.cpp（重置）。
