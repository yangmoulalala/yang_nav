## 修复内容

### 碰撞检查与失败传播

- 新增 `costmap_collision.hpp`：用凸多边形与占用格的分离轴检测覆盖完整足迹，包括完全落在足迹内部的占用格；未知和越界拒绝。运动段按半栅格步长插值检查平移和旋转。
- 去掉原实现收缩 4 cm 足迹的做法。整形器与区域控制器的 `collision_tolerance` 默认均为零，非零配置拒绝启动；保留实际 footprint padding。
- 整形器对稀疏输入加密，减少跨过小区域不整形的可能；对输出段做运动足迹检查。缺代价地图、必要整形失败或整形后碰撞均抛 Nav2 错误，不能静默返回原路径并报告成功。
- 区域控制器检查实际位姿、前方参考路径以及当前速度和新命令的制动轨迹，包含侧移、旋转和倒行。持续阻塞超过配置时间返回控制失败。
- 控制器校验输入路径 frame/非空，允许单点到达路径；非法速度限制归零，保留 Nav2 的 0 表示无限速约定。

### 区域起终点与状态机

- 支持区域内部起点、终点以及整条路径均在区域内部的正反向跟踪。
- 短入口保留真实起点，通过前进中的横向过渡接轴线，避免把机器人起点直接搬到轴线上。
- 保留用户目标位置及最终朝向；内部目标与区域约束冲突时失败，不静默改目标。内部目标不在到达前错误交回 MPPI。
- `ahead()` 从最近投影点重采样，支持正/负距离并包含终点，碰撞姿态使用实际选择的 0/π 航向。
- reset 清理旧锁定与退避；APPROACH 允许重规划，ALIGN/TRAVERSE/EXIT 才暂停。

### 恢复与行为树

- 恢复增加基于 TF 的实际区域占用判断。保护范围为受约束区域外扩 0.55 m；缺失/过期 TF 禁止运动恢复。
- 同一失败链一旦触发区域保护就锁存，停车导致 phase 心跳超时不会解除。执行中的 spin/backup 也会被保护条件中断。
- 新目标打断旧导航/恢复子树并重置恢复阶梯；暂停区域重规划前先检查目标变化。
- 新增 `navigate_through_poses.xml`，让多目标导航同样执行整形、暂停和区域恢复保护，避免走 Nav2 默认树绕过保护。
- launch 为两个 BT 注入真实 zones 文件；错误上报加入 smoother error code。
- phase 新鲜度拒绝 NaN/Inf 和负时间差，接收端丢弃未来消息，换 topic 时移除旧 callback group。完整时钟回退重置仍是待办。

### 验证工具

- 新增 `framework_accept.py`，启动真实 Nav2 全栈，用最终 `/cmd_vel` 积分确定性全向运动学 plant，发布测试 TF/odom/观测/可信状态；默认 domain 86。
- 冒烟增加 collision_monitor 对近距离障碍实际减速的断言，默认 domain 85；恢复测试默认 domain 87。
- 障碍过滤新增位于有效高度范围内的顶棚测试，避免仅靠 max_height 过滤就假通过。
- `plan_tunnels.py` 必须检查规划/整形 action 状态与 error_code，保留请求的起终点航向。旧工具会统计 ABORT 返回的原路径，旧“12/12”因此不能作为完成依据。
- 新增只读 `terrain_check.py`，检查必要文件、地面高程、净高完整性和源项目一致性；不写地图和标注。

单测按当前 CMake 启用目标统计：nav_behaviors 8 个目标 / 72 个用例，nav_safety 1 / 9，nav_terrain 3 / 26。旧构建目录残留已删除测试 XML，`colcon test-result` 汇总还包含重复和旧结果，不引用其 325 数字。

13 项闭环覆盖：

1. 所有 lifecycle 节点激活，生产安全门启用。
2. 平地到点及指定航向。
3. 真实规划、整形、跟踪链穿越隧道，体内横向误差 ≤3 cm、航向误差 ≤3°。
4. 倒行进入区域内目标并停车。
5. 区域内闲置 5 秒后目标不可达，只清图、不 spin/backup。
6. 从区域内重新下发目标并反向退出。
7. 动态障碍停车，障碍消失后继续到达目标。可能重规划绕行，不保证保持原路径。
8. 区域内取消终止 action 并输出零速度。
9. 取消后的新目标能继续完成。
10. 区域内行驶时抢占新目标，旧 action 终止，新目标完成。
11. 观测断流或定位不可信状态停车，恢复后继续。
12. NavigateThroughPoses 经过方向地形，进入 ramp 模式并完成末目标。
13. 已到达目标再次下发，不进入恢复。

这些结果验证真实 Nav2 软件接线和运动学闭环，不验证 Gazebo/真车的俯仰、打滑、净高、轮胎接触或真实制动距离。

地形数据的独立发现：

- 当前 `maps/sim/terrain/terrain.msgpack` 的 `clearance` 是 None，顶棚过滤所需数据缺失。
- 地面 elevation 与 `maps/sim/sim.surf.npz` 的 z 逐格一致。旧记录“统一偏高 11～13 cm”尚未通过绝对高程/原始点云比对确认；直接重导相同源项目不会改变地面高程。
- 源项目 674 个 tunnel 标注格仅 202 格有限 clearance，其余为 inf；有限值约 0.250～0.431 m。需核查顶棚覆盖和标注边界，重导不能凭空补齐源数据。
- 本轮没有改动这些数据，也没有增加运行时强制拒绝缺 clearance 的启动条件；只读检查失败必须纳入场地验收。
